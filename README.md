# VS Code plugin

A VS Code extension that shows server-pushed alerts (with 1–2 action buttons) and
provides a toolbar entry point that opens a form panel, submitting both the alert
responses and the form payloads back to a server.

See [docs/DESIGN.md](docs/DESIGN.md) for the high-level design: architecture, wire
protocol, auth model, reliability strategy, and the phased build plan.
